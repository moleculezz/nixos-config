# .nixos-config

Personal NixOS flake for `gnix` (Framework 13 AMD), organized with the
**Dendritic Pattern**: [`flake-parts`](https://flake.parts/) +
[`import-tree`](https://github.com/vic/import-tree).

## Layout

- `flake.nix` — minimal entry point. Never needs to change when modules are
  added or removed: `inputs.flake-parts.lib.mkFlake { inherit inputs; } (inputs.import-tree ./modules)`.
- `modules/` — every `.nix` file here is a self-contained flake-parts module,
  auto-discovered by `import-tree`. Most contribute a
  `flake.modules.nixos.<aspect>` (e.g. `crypto.nix`, `office.nix`,
  `libvirt.nix`).
- `modules/settings.nix` — declares a shared `settings` option
  (username, hostname, system, etc.) that other modules read via
  `config.settings.*` instead of passing values through `specialArgs`.
- `modules/hosts/gnix.nix` — assembles `flake.nixosConfigurations.gnix` from
  the aspect modules in `modules/`.
- `hosts/gnix/` — host-specific, non-dendritic files: `disk-configuration.nix`
  (disko layout) and `hardware-configuration.nix` (generated by
  `nixos-generate-config`).
- `dotfiles/` — plain dotfiles managed manually with
  [GNU Stow](https://www.gnu.org/software/stow/), not home-manager.

## Installation instructions

Download and use the [NixOS minimal ISO image](https://nixos.org/download/#nixos-iso)
and create a USB boot disk for the installation. Boot the installation media
and execute the following:

```
cd /tmp
nix-shell -p git
git clone <this-repo-url> nixos-config
exit
cd nixos-config/
sudo nix run 'github:nix-community/disko#disko-install' --experimental-features 'nix-command flakes' -- --write-efi-boot-entries --flake '.#gnix' --disk nvme0n1 /dev/nvme0n1
sudo reboot
```
USB boot disk can now be removed.

### Initial system boot

Now that the system has booted for the first time, change the default
password (currently "changeme"):
```
passwd
```
Then rebuild NixOS:
```
cd ~
git clone <this-repo-url> nixos-config
cd nixos-config
sudo nixos-rebuild switch --flake .#gnix
```
